# Corpus Fixtures

This directory contains the small attribution-cleared corpus used by `pnpm eval`.

Source text: Regulation (EU) 2024/1689, Article 50, German text. The source is
EU legal text; the fixture cites the source URL and keeps the excerpts narrow so
test failures remain readable.

Source URL used for the v1 fixture:
https://gesetze.legal/eu/vo_eu_2024_1689/50
