# EU AI Act Article 50 Report

The v1 report generator emits `disclosure.json`, a Typst-rendered
`disclosure.pdf`, and a sealed `audit-excerpt.zip` for a requested time window.
The report includes system identity, deployment context, model versions, prompt
versions, embedding versions, corpus snapshot identity and hash, query volume,
outcome breakdown, eval scores, refusal rate, prompt appendix, limitations,
human oversight text, and the audit excerpt hash.

The package is a transparency artifact, not legal advice or conformity
assessment.
