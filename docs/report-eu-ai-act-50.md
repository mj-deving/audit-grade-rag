# EU AI Act Article 50 Report

The v1 report generator emits deterministic JSON, deterministic PDF bytes, and a
sealed audit excerpt for a requested time window. The report includes system
identity, deployment context, model versions, prompt versions, embedding
versions, corpus snapshot identity, query volume, outcome breakdown, eval scores,
refusal rate, prompt appendix, limitations, human oversight text, and audit
excerpt hash.

The package is a transparency artifact, not legal advice or conformity
assessment.
