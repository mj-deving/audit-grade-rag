# Operator-Handbuch

Audit-Grade RAG ist ein KI-System fuer belegte Korpusantworten. Operatoren
melden sich per Magic Link fuer Bootstrap oder Recovery an und verwenden danach
Passkeys. Passwortfelder existieren nicht.

In der Konsole stellt der Operator eine Frage, prueft Antwort, Zitate,
Korpusstellen, Audit-Zeile und Replay-Status. Eine Verweigerung ist ein gueltiges
Ergebnis, wenn keine ausreichende Korpusevidenz gefunden wurde. Blockierte
Antworten duerfen nicht als finale Antwort verwendet werden.
